Languages: English, Russian.
List of languages supported by the Google online translator: English, Russian, German, French, Belarusian, Ukrainian, Lithuanian, Latvian.

Yandex search is available in all localizations.
When sharing a page, only the URL is passed.
Web pages are saved with the .mhtml extension.
The logo on the home page has been moved to the top.
Icon labels on the home page are displayed in two lines.
Requests permissions on first launch.
The keyboard in the address input field switches to the appropriate one.
On the history and bookmarks pages, accessed via long press, icons and web addresses are displayed.
Some default settings have been changed.
Analytics has been removed.
After closing, the app does not remain in active processes.
